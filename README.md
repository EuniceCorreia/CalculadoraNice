# 📱 Calculadora Nice

Uma **calculadora simples e funcional** desenvolvida em **Kotlin** com **Jetpack Compose** para Android.  
Este projeto foi criado como parte do **Exercício 3** da disciplina de Desenvolvimento Mobile, com o objetivo de praticar o uso do **Android Studio**, **Kotlin** e os conceitos de **UI declarativa** com Compose.

---

## 🚀 Funcionalidades

✅ Operações básicas: **soma (+)**, **subtração (-)**, **multiplicação (×)** e **divisão (÷)**  
✅ Botão **C** para limpar o visor  
✅ Exibição de **entrada** e **resultado** em tempo real  
✅ Interface responsiva e moderna, seguindo os padrões do **Material Design 3**  
✅ Compatível com modo claro/escuro (dependendo do tema do sistema)

---

## 🧩 Tecnologias Utilizadas

- [Kotlin](https://kotlinlang.org/)
- [Jetpack Compose](https://developer.android.com/jetpack/compose)
- [Material Design 3](https://m3.material.io/)
- Android Studio (versão recomendada: **Giraffe** ou superior)
